感染力的六个原则：社交货币：诱因；情绪；公共性；实用价值；故事；
## 一、社交货币

### 1. 社交货币的形成原因

+ 自由表达和披露信息对自己本身就是一种内在的奖励，人们倾向于分享自我感受，为此甚至能接受一定限度的利益损失；
+ 口碑的传播是为了保持人们对自己的良好印象，所以人们倾向于分享他们所能见到对自己有益的事物，以营造更良好的人设；

### 2.  社交货币的铸造方式

1. **发掘标志性的内心世界**：
	+ 非常规的、具有超出想象、具有争议性、和具有神秘性的事情能引起人们更频繁的关注，并使谈论这些事情的人更受人瞩目；
	+ 记忆功能具有局限性，只能形成一些选择性记忆，并在传播中补全剩余的骨架，如果故事本身是正向的，考虑到上一条，那么这种大众传播一般也是正向的，并会更加具有魅力；
2. **撬动游戏杠杆**：
	+ 人们倾向于相对收益较高，而不是绝对收益较高的方案；人们不仅关注自己是如何完成任务，也关注自己行为对他人的影响和差别；
	+ 利用游戏身份层级的划分，可以利用社交货币撬动很高的收益：因为杠杆游戏的本质就是让我们挣得更多的社交货币，让我们看起来比他人更加聪明或者更有实力；
	+ 这种杠杆游戏必须要有明确划分、显著具有区分度的度量标注，让人们知道并记录自己所达到的成绩或者成就：
		+ 正面例子：航空里程会员；
		+ 反面例子：不同材质颜色的信用卡让人混乱；
3. **使人们具有自然天成、身临其境的归属感**：
	- 运用稀缺性、专用性的特点让客户更有归属感和满足感：
		- 正向例子：山姆会员、限时抢购、饥饿营销；
	- 稀缺专用性甚至可以人为构建，作为杠杆游戏的惩罚项使用；
	- 相同但稀缺的的社交背景会使得人们更亲近和便于交流，进一步的促进了归属感：
		- 正向例子：某品牌的定期车主集会，二次元亲友扩列；
	- 相对于金钱刺激，荣誉感和或者其他形式的物质奖励会提高人们自发传播的动力；

## 二、诱因

### 1. 临时传播与持续性传播

+ **临时的口碑传播**：有趣新奇的产品获得更多的关注；
+ **持续的口碑传播**：
	+ 视觉、嗅觉、听觉、味觉都能诱导思想与想法，这与有趣性、刺激性并无显著关联。
	+ 这也是为什么高频的广告也能增加销量，均衡饮食的标语虽然无聊但是放在餐厅也有效果；
	+ 但越是潜意识的行为越受这种诱因影响，大宗商品购物或者深思熟虑行为影响就会少的多；

### 2. 有效的诱导性关联
1. 诱导性关联频率越高，越能够获得传播的机会，越会转向持续性口碑；
	+ 日常问候语和商品进行关联：百威啤酒广告词；
	+ 特定时间与商品关联：疯狂星期四；
2. 生活环境的不同会有不同的诱因：
	+ 新年里红色产品包装会更加受到关注；

## 三、情绪

结论：**高唤醒度的情绪会有更高的传播度价值**；这种情绪甚至不仅仅取决于消息的传播，身体激素变化（如跑步后）也能激发共享意识；
### 1. 情绪的维度：原理可以参考[[大脑中的秘密#神经递质的应用]]相关章节

|        | 高唤醒         | 低唤醒 |
| ------ | ----------- | --- |
| **积极** | 敬畏、消遣、兴奋、幽默 | 满足  |
| **消极** | 生气、担忧       | 悲伤  |

### 2. 情绪的示例

| 情绪  | 示例         | 唤醒度 | 传播效果 |
| --- | ---------- | --- | ---- |
| 敬畏  | 科技的进步性创新   | 高唤醒 | 增加传播 |
| 焦虑  | AI产业的发展    | 高唤醒 | 增加传播 |
| 悲伤  | 明星动物去世     | 低唤醒 | 减少传播 |
| 愤怒  | 贪污丑闻       | 高唤醒 | 增加传播 |
| 兴奋  | 滑稽出丑的短视频   | 高唤醒 | 增加传播 |
| 紧张  | 警匪片模式的汽车广告 | 高唤醒 | 增加传播 |

## 四、公共性

1. 社会证明：在没有特定倾向的情况下，人们会模仿其他人的选择：
	+ 水果店打窝现象，生活中的贝叶斯概率学；
	+ 网红餐厅的火爆现象；
2. 隐密的事物可视化：
	+ 以特定并且醒目的标语、徽章、穿着、品牌标志等显化要宣传的事物。既能增加模仿，也是一种诱因传播；
	+ 正向例子：黄腕带、使用IPhone 手机发送的默认标注；
	+ 反面例子：反毒品广告的普及让吸食大麻的人变多了，因为多数人都在吸食大麻，且广告更频繁的触发他们的兴趣；

## 六、故事

1. 相比较于广告，人们更少排斥故事；
2. 故事能够承载文化属性、社交属性等，并且具有更大的传播价值；
