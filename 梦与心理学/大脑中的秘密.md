# 大脑中的信息传递

## 1. 信息传递的两种方式

| 传递方式           | 优势                                                      | 缺点                          | 应用场景            |
| -------------- | ------------------------------------------------------- | --------------------------- | --------------- |
| 电突触            | 数字化开关。传递信号速度非常快，突触连接数量少；                                | 缺乏增益，信号会在连接过程中损失，导致连接层级比较少； | 反射反应等需要急速反应的功能； |
| 电信号律动（脑波）      | 与具体的大脑区域与清醒程度有关，使神经元同步；                                 |                             | 睡眠              |
| 化学物质<br>（神经递质） | 更加灵活，类型丰富；<br>1. 可以信号增益，或者减益；<br>2. 受体不同，允许通过的离子、方向也不同； | 传递速度稍慢；                     | 大部分功能；          |
+ 一般情况下神经细胞带负电，与外界形成一个电压差，称为膜电位；细胞膜上充满着受体，受体被打开时，就会在细胞膜上形成通路，膜电位变化。当变化到临界电时，产生连锁反应，更多正离子进入细胞内，产生一个动作电位；
+ 突触间隙（细胞与细胞之间的缝隙）之前的神经细胞（突触前膜）会释放出神经递质，自由的悬浮在突触间隙中，触碰到突触后膜中的受体，引起突触后膜的变化；
## 2. 神经递质的定义

1. 必须在突触前膜中合成，且在前膜集中保存于一个个囊泡之中；
2. 当神经细胞受到刺激后，神经递质会从突触前膜释放到突触间隙中；
3. 在神经递质被释放后，能作用于突触后膜，并引起突触后膜的变化，并在发挥作用后，作用会自动并迅速地终止；

## 3. 脑波的频率

| 脑波种类   | 赫兹     | 状态           | 示例           |
| ------ | ------ | ------------ | ------------ |
| Delta波 | 1~4    | 深度睡眠（非快速眼动期） | 无意识状态        |
| Theta波 | 4~7    | 快速眼动期睡眠、冥想   | 梦见出去旅行       |
| Alpha波 | 7~12   | 平静、放松状态      | 思考来一场说走就走的旅行 |
| Beta波  | 12~30  | 思维集中、耗费智力的活动 | 做旅游计划        |
| Gamma波 | 30~100 | 高度警惕、焦虑      | 发现银行卡余额不足    |

## 2. 关于爱情

**（去甲）肾上腺素决定出不出手，多巴胺决定天长地久，血清素决定谁先开口，端粒酶决定谁先走；**
+ 去甲肾上腺素和冲动、觉醒有关，负责情绪唤起和性唤起；
+ 多巴胺会让大脑原本的动机和奖赏机制发生变化；《暮光之城》中有句话：“You are lik my own personal brand of heroin.” (你是我的专属海洛因)
+ 血清素有让人冷静放松的效果，而热恋状态下大脑中的血清素含量较低；
+ 端粒酶是一种存在于身体细胞中的梅，和人体衰老及癌症有关；

**爱情主要有三种状态：情欲、吸引和依附；**
+ 情欲：和睾酮、雌激素有关；
+ 吸引：和去甲肾上腺素、多巴胺、血清素有关；
+ 依附：和抗利尿激素、催产素有关；

**巧克力与爱情的误会**
+ 苯乙胺和多巴胺强相关，能够令人兴奋，产生幻觉；
+ 巧克力中含有苯乙胺，但是苯乙胺吃下去后很快被分解为其他物质，并不能直接进入身体；

## 3. 关于减肥

**高蛋白-无碳水减肥法的流行**
+ 血清素的产生速度是有色氨酸完全控制的，而它的合成必须由外界摄入，一般是由高蛋白食物提供；
+ 高碳水化合物 = 高热量；但高蛋白+无碳水化合物 不等于快乐减肥；
+ 虽然高蛋白确实能够产生大量的色氨酸，但是氨基酸进入血氧屏障时会相互竞争，导致进入大脑里的色氨酸变少，进而降低了大脑里的血清素含量，进而产生焦虑、失眠和想吃碳水的冲动；
+ 因此少量碳水有利于减肥；

## 4. 关于成瘾性不良习惯：

**吸烟有害健康，且容易上瘾的原因**
+ 香烟内含有大量的尼古丁，结构非常类似于乙酰胆碱，会模仿后者的活动，激活乙酰胆碱受体；
+ 但是尼古丁对于乙酰胆碱受体的结合远远高于乙酰胆碱本身，且很难被其他酶分开；
+ 尼古丁有着和乙酰胆碱相似的功效，会让人有能量感，但是随着大脑阈值的提高，这种能量感带来的效果会越来越小，而且不吸反而会有疲惫感；

**酒精为什么让人上瘾**
+ 酒精能够提高GABA的工作效率，让人放松、缓解焦虑；
+ 多巴胺上也有GABA的受体，因此抗焦虑和酒精也会让人上瘾；

**赌博的成瘾性原理**
+ 多巴胺的奖励是通过大脑的预测机制，准备实施行为时就已经预先出现，而非事后对行为进行奖励；
+ 因此越是超出预测范围，多巴胺分泌的奖励越多。当某种机制可以被预测并多次验证后，奖励反而会被逐渐减少；
+ 但是在某种不确定性面前，奖励系统甚至通过多巴胺的控制来成倍增加满足感。
