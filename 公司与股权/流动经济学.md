## 一、经济学基础

### 1. 基础名词

1. **量化宽松（QE）**：是央行在利率降至零后，通过直接购买国债等资产向市场注入基础货币的非常规货币政策。
	- 核心逻辑：当传统降息工具失效时，央行通过扩大资产负债表，压低长期利率、推高资产价格、刺激信贷和通胀预期，以对抗通缩和经济停滞。
	- 核心：用货币扩张替代价格调控。
2. **准备金**：
	- 是指商业银行按照规定，必须将其吸收存款的一定比例存放在中央银行的资金。这部分资金银行不能用于发放贷款或其他投资，是强制性的资金"冻结"。
	- 上调准备金率代表经济过热、通胀压力大，需要收紧银根，减少货币供应，抑制信贷扩张；下调准备金率代表经济下行、通缩风险，需要释放流动性，刺激信贷，支持经济增长；
	- 发达国家长期实行低准备金率，降低对银行的隐形成本，更偏好价格型工具（政策利率）；而新兴市场则由于金融市场深度不足，利率传导不畅、外汇占比过大等因素仍频繁使用准备金工具；
3. **正回购/逆回购**：
	1. 定义：
		- 正回购：中国央行卖出有价证券，并约定未来买回，资金从市场流向央行，造成流动性收紧；
		- 逆回购：中国央行买入有价证券，并约定未来卖出，资金从央行流向市场，造成流动性投放；
	2. 作用：
		- 逆回购是当前中国央行最常用、最灵活的日常工具，承担着短期政策利率锚和流动性"削峰填谷"的双重职能；
		- 正回购在流动性过剩时期使用，近年随着中国央行资产负债表扩张，已较少出现；
	3. 分类：
		- 7天期逆回购：作为短期政策利率（约1.8%），承担着调节日常流动性和引导短期市场利率的核心职能；
		- 14天和28天逆回购则主要用于满足跨月、跨季等特殊时点的资金需求，平抑季节性波动；
		- 中期借贷便利（MLF）以1年期为主，作为中期政策利率（约2.5%），通过向银行体系提供中期基础货币，直接引导贷款市场报价利率（LPR）的变动，从而影响实体经济融资成本。
4. **套息交易**：借入低息货币（如日元）进行融资，兑换为高息资产（如美元债）赚取利差的套利策略。但汇率波动会造成低息货币升值，利差收益将被汇率损失吞噬，尤其在危机时引发集体平仓踩踏。
5. **贴现率（discount rate）**：
	- 央行视角下：中央银行贷款给商业银行所收取的利率称为贴现率。它是央行货币政策工具箱中的重要组成部分：当商业银行面临短期流动性紧张时，可以直接向央行借款，此时适用的利率即为贴现率。降低贴现率意味着向市场释放资金，刺激经济增长；提高贴现率意味着收紧货币供应，抑制经济过热和通货膨胀；
	- 估值投资视角：将未来支付改变为现值所使用的利率，代表资金的时间价值。当企业持有一张尚未到期的商业汇票，可又急需用钱的时候，就会拿着这张汇票到银行去贴现。银行可不是慈善机构，它会依据一定的贴现率，从汇票的票面金额中扣除从贴现日到票据到期日这段时间的利息，然后把剩下的钱付给企业。  
### 2. 基础知识
1. 从历史角度来看，任何国家都从来没有真正清偿过它们的债务；实现美元信用本位制后，各主要存续经济体的负债率就在一直上升，央行的资产负债表也在不断地膨胀；
2. 货币存在三种价格：物价、利率和汇率，分别是货币的对内价值，时间价值和对外价值，也可以理解为货币之于商品的价格，货币作为金融资产的价格和货币的相对价格。
	1. 货币的时间价值是其他金融资产定价的一个基准，因为最基本的定价模型就是现金流贴现，对应货币的时间价值就是贴现率；
	2. 货币的商品价格，即一般意义上的货币购买力，是深化金融改革的基础。
3. 央行的货币发行必须要有相应的资产做支撑，本质上是资产创造货币（与商业银行用负债创造货币的机制正好相反）。这种资产主要来源于三个渠道：
	1. 对应政府的债权（本国国债），这是以政府的税收征管权作为发行保障的；
	2. 对应金融机构的再贷款，这是以金融机构的盈利能力作为发行保障的；
	3. 外汇占款，央行在发行本币兑换等值外币的同时，具有了对国外商品的要求权；
4.  中国的金融特点：
	- 是货币的储备国而非发行国，外汇占款是经济全球化以后流动性急速扩张的源泉；
	- 以银行间接融资为主导，国有银行为主体，实施利率管制与信贷控制和配给是货币调控的基本内容；
5. 金融抑制的政策：
	1. 利率管制，存在较低或者负的实际存款利率；
	2. 高存款准备金率或者准备金税；
	3. 政府干预信贷投放的干预或者歧视性信贷政策；
	4. 资本账户管制；
6. 赤字类型：
	1. 财政赤字：政府支出 > 税收收入，需发债融资；
	2. 经常账户赤字（跨境汇总，衡量一国储蓄与投资缺口）：进口 + 对外投资 > 出口 + 外资流入，需借入外币平衡；
7. 失踪的货币：
	1. 传统的货币数量学说认为：物价水平的高低和货币价值的大小为一国货币数量的多少所决定，货币数量的增加会导致物价正比例的增加，而货币的价值则反比例下降，反之亦然；
	2. 失踪的货币指这样一种经济现象：货币供应的增长远高于GDP增长的速度，却没有引来上规模的通货膨胀；
	3. 中国长期处于金融抑制条件下，失踪的货币只是去填补了尚未被货币化的子市场空白，在填满后终究会形成流动性过剩；

## 二、中国外汇的金融模型

### 1. 汇率并轨制度（1994-至今）

1. 汇率并轨是指将并存的官方汇率、市场汇率这种双重汇率合并为单一汇率制度的改革。
	- 在1994年改革前，中国实行汇率双轨制：官方汇率（1美元=5.8元人民币）主要调节计划内的外汇收支、进口贸易；外汇调剂市场汇率（1美元=8.7元人民币）主要调节计划外的外汇收支、外资企业等。这两个汇率之间存在巨大套利空间，造成寻租腐败，并造成市场混乱。
	- 1994年以后，并轨后汇率定为1美元=8.70元人民币，人民币一次性贬值约50%。
2. 总结来看，汇率并轨制度改革
	1. 修正了长期高估的问题，出口竞争力大幅提升；
	2. 经常账户由逆差转为顺差,国际收支改善。
	3. 外汇储备快速增长，外汇开始向央行集中。
### 2. 强制结售汇制度（1994-2012）

1. 强制结售汇制度是指居民（企业和个人）取得的外汇收入，除国家允许开立外汇账户予以保留的外，必须卖给国家指定的金融机构（外汇指定银行），使用外汇时再从这些金融机构购买的管理安排。
2. 优势：强制结售汇制度是外汇短缺时代的产物，在特定历史阶段发挥了关键作用：
	- 通过集中外汇资源，快速积累外汇储备；
	- 为进口支付和基础设施建设提供外汇保障；
	- 在资本项目未开放情况下，防范外汇风险，维护国家经济金融安全；
3. 隐患：
	- 削弱货币政策独立性：外汇占款持续增加导致央行被动投放基础货币，引发了通胀压力；
	- 转嫁外汇风险：将居民与企业的外汇风险转嫁给中央银行；
	- 限制企业自主权：企业无法根据经营需要自主管理外汇资金，增加汇率风险管理难度;
### 3. 浮动汇率制度与强制干预

1. 强制结售汇制度下，央行被动投放基础货币的核心逻辑是：企业出口创汇 → 必须卖给银行（强制结汇） → 银行卖给央行 → 央行支付人民币 → 基础货币投放 → 外汇占款增加。央行作为被动买家，必须不断购入商业银行卖出的外汇。
2. 中国实行有管理的浮动汇率制度，为维护汇率稳定，央行必须入市干预：当外汇供给 > 外汇需求时（市场上美元过多，人民币相对稀缺），外汇价格（汇率）下跌，即人民币升值；反之则贬值。因此当外汇供大于求（顺差时），央行必须买入多余外汇，否则人民币升值压力过大；
3. 央行干预方式：
	- 投放基础货币（非冲销式，即货币总量变化）：
		- 顺差时买入外汇，投放本币（2002-2014年的常态），此时货币供应量(M2)激增，增加通货膨胀压力；
		- 逆差时卖出外汇，回笼本币（2015-2016年、2022年曾出现）；
	- 发行央票（冲销式）：
		- 央行发布中央银行债券代替直接投放本币，商业银行用超额准备金购买央票，回收流动性；
		- 但是这一操作需要央行持续支出利息；
	- 调整存款准备金（冲销式）：
		- 货币供应量由两个因素决定：货币供应量(M) = 基础货币(B) × 货币乘数(m)。尽管基础货币提高，但是通过控制准备金，也能间接控制通胀。
		- 缺点：只能大致对冲，难以精确匹配；并且存在时滞，只能在数据公布后调整；

## 三、美元驱动的世界模型

### 1. 消费国：货币特权

1. 经典代表：美国，特点：印刷货币，累积债务，输出资本；
2. 美国的赤字和债务源于为世界提供流动性：世界的发展需要国际货币，在美元信用的本位制下，为发行货币提供担保的是美国政府而不是黄金。20世界70年代以来，因为没有足够的商品输出和资本输出相互抵消，美国政府必须向国外借债以保证美元的信用。
3. 国外企业通过贸易获得美元，在本国无法直接使用，只能通过央行结汇换取本币，于是通过央行再贷给美国（央行一般用于购买最安全、流动性最好的美元资产，美国国债），美国政府将这笔钱反过来用于国内。
4. 由此，同一笔美元同时在外国创造了本币流动性（第一层信用），又通过美国财政支出转化为国内购买力（第二层信用），形成"1美元变2美元"的杠杆效应。同一笔贸易产生的美元，通过金融系统同时在两国创造了购买力。在这个循环里，不是消费导致债务，而是债务促进消费（类似于贷款生成存款，而是存款生成贷款）。
5. -这是美元霸权的特权：只有储备货币发行国才能这样向全世界借钱消费；外国央行的两难：不买美债，美元储备贬值；买了，就是在资助美国消费；
6. 美国处理贸易逆差的方法：
	1. 劝说或者胁迫其他国家调整宏观政策
	2. 放任美元贬值；
	3. 调整美国国内政策；
### 2. 生产国：国际分工

1. 日本：
	1. 1985年《广场协议》造成日元升值，牺牲了日本的贸易，造就了东南亚经济的奇迹；
	2. 2001年，日本央行正式推出量化宽松（QE），成为全球首个实施该政策的央行；低利率的日元开始成为国际金融货币的主要拆入货币以进行套息交易。
		1. 投资者在日本低息融资，增加日元供给，并在兑换外币中卖出日元、买入高息货币，直接压低日元汇率；
		2. 这种交易平息了贸易顺差造成的日元升值压力，也成为了日元汇率保持均衡的的主要原因；
	3. 美联储2008年后大规模QE与欧元区同样采用长期低利率政策，大量套息交易被解除，提高了日元汇率，日元不断升值；
	4. 2012年，安倍经济学采用超宽松量化质化宽松，主动进攻型的全面刺激方案：
		1. 通过无上限购买长期国债及风险资产、实施负利率与收益率曲线控制，并辅以扩张性财政和结构性改革协同发力，旨在强制制造通胀、彻底摆脱通缩陷阱。
		2. 该政策短期内激活了市场（2012-2015），但并未改变长期的经济困境，日本陷入"低增长、高债务、超宽松"的新常态陷阱。
2. 中国：
	1. 人民币的有限兑换性：人民币在资本账户下存在管制，不能自由跨境流动，与经常账户可兑换形成对比。人民币的跨境投资、借贷、衍生品交易需审批或额度限制;
		1. 年度5万美元便利化额度，不得用于境外购房、证券投资;
		2. 证券投资：通过QFII/RQFII（外资进场）、QDII（内资出海）等管道配额管理‘
		3. 汇率形成：中间价定价机制、逆周期因子调节，非完全市场浮动
	2. 人民币的生产货币性：货币扩张以实体经济增长为载体，有强大的产能和外汇储备支持，有健康的对外资产负债表和潜在的庞大市场；
	3. 由于中国拥有丰富生产要素，因此形成了竞争式贬值：钉住汇率会造成竞争力下降，增长放缓；而紧跟人民币对美元贬值，国家福利就会下降，国内价格水平上升；这一过程中处于产业升级过程中的欧美国家成为最大的收益者；
	4. 以1994年的汇率并轨为标志，中国取得了国际市场上的第一次角力胜利：
		1. 菲律宾、印度、印度尼西亚等国家由竞争性贬值转为固定利率；
		2. 泰国、马来西亚这种一直采用固定汇率的国家由于本币高估，成为之后亚洲金融危机中的攻击靶子；

### 3. 资源国：殖民地

1. 大部分商品以美元结算：无论资源的购买者是谁，最终都会导致国际货币数量的增加。而无论是通过进口、消费还是国内投资，资源国的实体经济往往难以吸收如此多的流动性，这些资金会以游资的形式活跃与国际金融市场中，石油美元就是典型；
2. 美国通过军备、经济等多种形式控制着石油命脉；

## 四、金融危机案例

### 1. 1997年亚洲金融危机
#### 1.1 背景

过早开放资本账户的国家盲目自信，且本土利率显著高于美日，套息交易为国家炒家提供了更加廉价的弹药，国际过剩资本在对冲基金的带领下变成投资基金，引发了金融危机。这些国家具有以下特征：
- 本外币自由兑换：方便建立空头头寸
- 短期资本自由进出：热钱可瞬间大规模流入/流出
- 离岸市场无管制：投机资金绕过本土监管
- 本土利率显著高于美日：低利率的日元为国家炒家提供了更加廉价的弹药
- 杠杆放大：对冲基金以5-10倍杠杆操，数十亿美元本金可控数百亿美元头寸，央行干预成本呈指数级上升

#### 1.2 案例：对冲基金的模式，1997年泰铢攻击的经典案例

| 阶段   | 操作            | 市场效应        |
| :--- | :------------ | :---------- |
| 建仓期  | 借入泰铢（远期、互换市场） | 积累空头头寸，隐蔽布局 |
| 现货冲击 | 抛售泰铢、买入美元     | 耗尽央行外汇储备    |
| 舆论造势 | 散布银行坏账、地产泡沫消息 | 触发市场恐慌      |
| 总攻   | 大规模做空泰铢期货、期权  | 汇率崩溃，固定制失守  |
| 收割   | 低价回补泰铢，偿还融资   | 巨额汇差利润      |
中国的防御政策：

| 措施              | 作用                  |
| --------------- | ------------------- |
| 人民币不可自由兑换       | 阻断国际投机资本直接攻击汇率渠道    |
| 严格的短期资本管制       | 热钱无法大进大出，离岸市场与在岸隔离  |
| 固定汇率制（8.28）     | 虽僵化但提供稳定锚，未成为攻击目标   |
| 充足外汇储备（1400亿美元） | 远超短期外债规模，具备干预底气     |
| 低外债率、高储蓄率       | 银行体系以存贷为主，未卷入国际信贷紧缩 |
