## 专有名词解释

**注册资本**，是公司在工商登记机关注册的法定资本总额，代表股东对公司承担责任的最高限额，体现公司初始规模和法律信用；在认缴制（如中国2014年后）下，无需设立时全额实缴，但股东需在章程中约定认缴期限；但是，虚高注册资本可能放大债务风险（如破产时股东须以认缴额为限补足），并影响VC/PE估值谈判；
+ **认缴出资额度**，指股东在公司章程中书面承诺向公司缴纳的出资金额及具体时间表，构成具有法律约束力的出资义务，但尚未实际支付；
+ **实缴出资额度**，指股东已实际缴付至公司银行账户的出资金额，是公司可支配运营资金的真实体现，直接影响财务健康度；

**虚拟持股**，是一种非股权激励工具，公司授予员工或核心成员虚拟股份的收益权，使其在公司估值增长或特定事件（如并购、IPO）时获得现金奖励，而不实际持有公司股票、享有投票权或承担股东义务；

**商业计划书**（Business Plan，简称BP），是创业者或企业向风险投资（VC）、私募股权（PE）等机构展示项目核心价值、商业模式及发展潜力的结构化融资文件；

**普通合伙人**（General Partner，简称GP），以较小的出资额度作为主要管理人，承担无限责任。通常需要获得超额利润后参与分配，但能够分配较高比例利润以进行激励；

**有限合伙人**（Limited Partner，简称LP），是私募股权或风险投资基金的主要出资方，承担有限责任，提供绝大部分资本，但不介入日常管理，只通过基金的投资收益分享长期资本增值；

**风险投资**（Venture Capital，简称VC），是一种专业投资机构通过募集基金，将资金投入具有高成长潜力但同时伴随高风险的初创期或成长期企业（尤其是科技创新型企业），以获取未来高额股权回报的投资方式；
+ 项目一般尚在早期，尚未盈利，估值较低但是风险较高；
+ 承担较高的失败风险的同时，并最终通过企业上市、并购或回购等路径实现资本退出；

**私募股权投资**（Private Equity，简称PE），是一种专业投资机构通过募集基金，将资金投入非上市的成熟期、转型期或需要重组的企业（包括杠杆收购、增长资本等），以获取控股权或重要股权并通过价值提升实现资本增值的投资方式；  
+ 项目一般处于成长后期或成熟阶段，已有稳定现金流或盈利模式，估值较高但风险相对可控；  
+ 通过企业上市、并购、管理层回购或二次出售等路径实现资本退出，持有期通常为3-7年；

## VIE架构详解

+ **定义**：VIE，可变利益实体，也称为协议控制；
+ **目的**：融资资金中存在外币，且境内本体公司A有计划在境外上市；
+ **实现**：在境外设立公司B，让这家公司以不占股的方式控制境内本体公司A，境外公司B可以凭借经并表获得境内公司A的业绩；
	1. 境外克隆：每个创始人以跟境内公司A同样的股权结构在开曼成立一家离岸公司，即开曼公司B；
	2. 入境设点：开曼公司B在中国成立一家外商独资企业C，未来资金可以从开曼公司B注入外资企业C；
	3. 夹层结构（可选）：境外公司设立外商独资企业C是，可以在香港设立一家公司，再由该司在内地开设外资企业C，以避免双重征税问题；
	4. 协议控制：外资企业C虽然不能成为境内公司A的股东，但是可以借款给境内公司A的股东，并与股东及公司签订一系列协议，将股权、表决权让渡给外资企业C；

## 退出机制

### 1. 融资退出机制

+ IPO退出：以设立可实际控制境内实体公司的离岸公司方式在境外上市；以境内股份制公司发行H股形式实现境外上市；境内公司在境外借壳间接上市；境内股份制公司在境内主板等上市；境内公司在境内借壳上市；
+ 并购退出：将股权转让第三方的方式实现退出；
+ 回购退出：因回购型对赌条约处罚回购（融资方业绩不达标处罚回购义务人的回购义务）；触发投资条件形成回购（投资期满N年无论业绩达标与否，都触发回购）；
+ 清算退出：法定清算、自行清算（根据预先设定的协议约定进行清算）；
### 2. 合伙人退出机制

- 预先做好参与股与资金股分离
- 预先做好退出惩罚金设置
- 约定优先退出后原价股（优先）回购

## 股权融资基础

**定义**：公司股东通过**增资**等方式向投资人**让渡部分股权**，为公司引入新的股东，同时**使总股本增加**的融资方式。
**特点**：
	- *不可逆性*：除对赌，回购等情况下，股权投资通常不可收回；
	- *长期性*：资金没有归还期限；与之相对，债券融资则有明确的归还日期；
	- *无负担性*：负债率会降低；与之相对，债券融资则因需要支付利息而增加公司负债率；
	- *控制权稀释*：股权融资需要降低融资方原股东的持股比例，创始人通常需要保留控制权。一般情况下，总股本会增加，但股权转让某些程度上也属于广义的股权融资；
**目的**：
	- 解决公司资金发展问题；
	- 以股权融资为股权定价（甚至可以利用对赌协议等，撬动更好的公司估值）

## 股权融资分类

- **融资渠道分类**：
	1. 通过IPO融资：拟上市企业依法经审核同意或者登记注册后，首次在交易所公开向投资者出售自己公司增发的股份，由此获得融资。通过该方式的融资效率最高；
	2. 通过新三板和区域性场外交易市场融资：IPO融资的低层次替代方案，融资对象的人数不能突破《公司法》对股东人数的限制；
	3. 通过私募股权基金融资：具有不公开、不进场的特点；
	4. 通过其他专业/ 非专业投资人处获得投资：专业投资人包括以股权投资为主营业务的个人和机构；非专业投资人包括：高净值自然人、公司员工等；
	5. 股权众筹：指公司面向多个投资者筹集一定比例的股份。注意，此方案有非法集资的风险；
- **按投资目的分类**：
	1. 战略投资者：为了谋求战略发展而进行相应投资行为的投资者，注重长期目标而非短期财务回报，能够辅助企业发展，对话语权较为感兴趣，如大型国企背景、政府产业投资背景、“产业链型”战略投资者；
	2. 财务投资者：注重某一个特定时期财务回报的投资者，期待企业上市而实现高回报退出，不谋求控股，基本不会干涉企业经营；
- **按融资轮次的分类**（基于企业生命周期理论）：
	1. 天使轮：投资人主要看业务逻辑，金额以300万居多。天使投资人为主要投资者；
	2. A轮：商业模式经过验证，业务初具规模，业内有一定地位或者知名度。以一两千万元居多，出让股权比例通常在10%。VC为主要投资者；
	3. B轮：企业商业模式和盈利模式已经得到验证，大多数居于行业第一梯队，融资金额在千万元~一两亿元之间，出让股权比例通常在在30%。VC为主要投资者；
	4. C轮：企业项目较为成熟，行内领先，准备上市。融资金额多在亿元级别。PE为主要投资者；
	5. D轮：扩大版的D轮融资；

## 股权融资主要条款

### 1. 投资人特权条约

1. **优先认购条款（优先认缴权）**：公司发行新股时，投资方作为原始股东可以按照原持有股份数量的一定比例优先于他人进行认购股权的权利；核心目的在于让投资人可以保证自己在目标公司占有一定持股比例，防止投资人股权不合理稀释；
2. **反稀释条款（反摊薄条款）**：目标公司进行后续项目融资或者定向增发过程中，私募投资人为了避免自己股权贬值或者份额被过分稀释而采取的措施；
	- 完全棘轮条约：指公司后一轮融资的股权价格低于前一轮投资人当时投资时适用的每股价格时，那么前一轮实际每股价格也要相应的调整；
	- 加权平均棘轮条约：指公司后一轮融资的股权价格低于前一轮投资人当时投资时适用的每股价格时，以所有股权的加权平均价格重新调整；
3. **优先购买条款**：原股东转让被投资公司股权时，投资人有优先购买的权利；
4. **禁售条款**：指未经投资人书面同意，创始股东不可出售其持有的公司股权，无论是采用对内转让还是对外转让的方式；
5. **共售条款（共同出售权）**：指目标公司首次发行之前，如果创始股东或者其他普通股东向第三方转让股权，投资人股东有权按照拟出售股权的股东与第三方达成的价格参与到这项交易中，按照其在目标公司中目前的持股比例向第三方转让股份；
6. **优先分红权条款**：指投资方有权先于其他股东分取被投资公司的利润；
7. **优先清算权条款**：指投资方有权在其他股东之前按照事先约定的方式获取企业清算价值的全部或部分；分为：无参与权的优先清算；有参与权的优先清算；
8. **否决条款（保护性条款）**：指投资人出于保护自身作为小股东的利益的考虑，以董事会或者股东的身份要求对公司的重大事项以及投资人重要利益相关事项拥有否决权；
9. **领售权条款（拖带权）**：指如果被投资企业在一个预定的期限内没有上市，或者双方实现约定的出售条件成就，则投资人有权要求创始股东和自己一起向第三方转让股权；
10. **回购权条款**：指投资人在特定情况下，要求公司或者创始股东以特定价格购回其持有的股权的权利，投资人要求的特定价格一般为投资人股本投入加一定溢价；
### 2. 对赌条约

定义：对赌条约又称估值调整机制（VAM），指投资方与融资方在达成股权性融资协议时，为解决交易双方对目标公司未来发展的不确定性、信息不对称性以及代理成本而设计的包含了股权回购、金钱补偿等对未来目标公司的估值进行调整的协议；
对赌目标：未实现合格IPO（赌上市），业绩未达预期（赌业绩），违法重要的陈述与保证或者其他约束（赌违约）、创始人或者核心团队离职（赌人才）、其他场景（兜底条款）；
对赌方式：
+ 调整持股比例或者赔钱；
+ 业绩补差：按照投资人可分得利润与实得利润的差额，对投资人进行投资；
+ 股权回购：对于资方的股权按照某个价格买回去；
