# 金融领域名词解释

----------

## 基础知识科普

-----------

**交易所（exchange）** 是金融市场和商品市场的核心基础设施，是为各类金融工具或实物资产提供集中交易场所与服务的法定组织。按交易标的可分为三类：

+ **证券交易所**：交易股票、债券、基金等证券（如中国沪深交易所、美国纽交所/纳斯达克）。
+ **期货交易所**：交易期货合约（如中国金融期货交易所的股指期货、芝加哥商业交易所的原油期货）。
+ **商品交易所**：交易大宗商品（如上海期货交易所的铜/铝、大连商品交易所的大豆/玉米、伦敦金属交易所的有色金属）。

**场内交易（Exchange-Traded）**是指在正式的交易所内进行的交易活动，优势在于可以实时交易，且一般情况下，场内基金相较于场外的交易费率更低；

**场外交易（Over-the-Counter, OTC）**是指在交易所之外进行的交易活动，每天只有一个价格，赎回资金到账需1–3个工作日（货币基金除外），因此流动性低于场内；一般使用第三方平台进行销售而无需证券账户，优势在于可以跟投或者智能定投。

------------

**一级市场（Primary Market）**，是新证券的首次发行与认购市场，亦称“发行市场”或“初级市场”，核心功能是实现资本形成，即资金需求方（企业、政府等发行人）通过直接出售新证券（如IPO股票、新发债券、私募股权）向资金供给方（投资者）筹集初始资本。它能够将社会储蓄转化为实体投资的源头通道，直接支撑实体经济的资本需求。

**二级市场（Secondary Market）**，是已发行证券的流通转让市场，亦称“交易市场”或“次级市场”。其核心功能是实现证券流动性与价格发现，即投资者之间买卖现有证券，完成风险再分配与资本高效配置。

| **对比维度**   | **一级市场（Primary Market）**                               | **二级市场（Secondary Market）**                             |
| -------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **定价方式**   | 承销商主导协商定价，二级市场价格水平会反哺一级市场发行定价（如IPO估值参考二级市场同类公司）。 | 市场化定价：依赖供需博弈的实时价格，反映市场对该证券价值的即时判断。 |
| **准入门槛**   | 认购者需具备较高资质（如机构投资者、合格个人投资者），对资金实力、专业能力有严格要求。 | 参与主体广泛（个人投资者、机构投资者均可参与），准入门槛较低。 |
| **证券流动性** | 所发行证券流动性极低：认购后通常存在锁定期（如IPO限售期），无法立即交易。 | 所发行证券具有高流动性：投资者可随时买卖，交易便捷。         |
| **监管重点**   | 严格准入审核：聚焦发行主体的资质审核（如企业财务状况、信息披露合规性）。 | 交易合规性监控：关注内幕交易、操纵市场、信息披露违规等交易环节风险。 |

## 理财分类介绍

**储蓄（savings）**  是经济主体（包括居民、企业及政府）将当期收入中未被消耗的部分存放于受保存款类金融机构（如商业银行、储蓄机构）的金融活动。储蓄提供本金的安全保障、适度的流动性以及稳定的利息收入，但由于现行利率低于CPI指数，银行存款实际上是负利率，达不到资产保值和增值的要求。

**债券（bonds）**是一种标准化的、可流通的债权债务契约，其本质是发行主体（包括主权政府、地方政府、金融机构及企业）为筹集资金而向投资者发行的、承诺按特定条件支付利息并偿还本金的固定收益证券，其市场价格与市场利率呈现根本性的逆向关系：市场利率上升则债券价格下跌，反之亦然。债券提供相对稳定的收益、较低的违约风险，并在投资组合中起到分散风险、对冲波动的作用。

**保险（insuraunce）**是指由保险公司按规定向投保人收取一定的保险费，建立专门的保险基金，采用契约形式，对投保人的意外损失和经济保障需要提供经济补偿的一种方法。目前，各大保险公司推出的分红型寿险品种，使得保险兼具投资和保障双重功能，但往往投资周期很长，且变现能力弱，收益也不高。

**固收类资产（fixed Income  Securities）**是资本市场中以固定或可预期现金流为特征的金融工具，其核心价值在于提供本金保障与稳定收益，通常具有优先于权益类资产的受偿顺位。此类资产通常包括债券（占比最高、流动性最强），优先股、结构性存款、可转债纯债部分等。固收类资产在资产配置中扮演“稳定器”角色，凭借低波动性与逆周期属性对冲权益市场风险，但需警惕流动性风险、通胀侵蚀实际收益及信用风险等结构性挑战。

**基金（Fund）**是指依法设立的集合投资工具，通过向投资者募集资金，交由专业基金管理人进行组合投资，以实现资产保值增值的金融产品。基金具有“管理人—托管人—投资者”三方结构：基金管理人负责投资决策与日常运作，基金托管人（通常为商业银行）独立保管资产并监督运作合规性，投资者作为委托人享有收益权。其核心优势在于可以通过资产配置分散非系统性风险、专业管理人依托研究团队实现信息优势，并通过规模效应降低交易成本。

**股票（Equity Securities）**作为资本市场中权益类资产的核心载体，本质是企业所有权的凭证。股票收益完全依赖于企业盈利分配（股息）及二级市场价格波动（资本利得），是企业未来盈利能力的证券化载体，其价值源于对实体经济的深度绑定，为投资者提供参与经济增长的杠杆。

**期货（futures）** 是一种标准化的、可流通的远期合约，其本质是交易双方在交易所集中竞价、承诺于未来某一特定时间和地点、以当前约定的价格交收特定数量和质量的标的资产（包括商品、金融工具及指数）的衍生金融工具。期货提供风险对冲、价格发现和杠杆投资的功能，但同时也伴随较高的保证金要求与双向的无限盈亏风险。

**期权（options）** 是一种标准化的、可流通的权利契约，其本质是期权的买方通过支付一笔权利金（期权费）给卖方，从而获得在特定日期或之前、以约定价格（执行价）向卖方买入（看涨期权）或卖出（看跌期权）特定数量标的资产的权利而非义务的衍生金融工具，类似一种“订金”。期权提供非对称的损益结构、精准的风险管理和杠杆投机机会，其买方风险有限（最大亏损为权利金）、卖方潜在风险较高，并在投资组合中起到保险、增强收益和构造复杂策略的作用。

**外汇交易（forex trading）** 是同时买入一批外币组合中的一种货币而卖出另外一种货币。外汇的双向交易非常灵活，没有时间限制，外汇交易者能自由地借助市场的涨势和跌势来获利，其“双向交易、灵活时间、高杠杆”的特性既带来了超额收益的可能，也隐藏着剧烈波动的风险。

| 投资工具   | 特点               | 风险      | 收益     | 流动性 | 适合投资者类型        |
| ------ | ---------------- | ------- | ------ | --- | -------------- |
| **储蓄** | 高流动性，保本保息，低门槛    | 低风险     | 低收益    | 极高  | 保守型投资者、初学者     |
| **债券** | 固定利息支付，到期还本      | 中低风险    | 中等收益   | 中高  | 稳健型投资者         |
| **股票** | 代表公司所有权，价格波动大    | 高风险     | 高收益潜力  | 高   | 激进型投资者、长期投资者   |
| **基金** | 专业管理，分散投资        | 取决于基金类型 | 中等至高收益 | 中高  | 所有类型投资者        |
| **固收** | 固定收入流，收益稳定       | 中低风险    | 中等收益   | 中   | 保守型至稳健型投资者     |
| **保险** | 保险保障+投资成分        | 低至中风险   | 低至中收益  | 低   | 长期投资者、家庭保障需求者  |
| **外汇** | 交易货币对，高杠杆，24小时市场 | 高风险     | 高收益潜力  | 极高  | 经验丰富的投资者、投机者   |
| **期货** | 标准化合约，杠杆交易       | 很高风险    | 高收益潜力  | 中高  | 专业投资者、高风险承受者   |
| **期权** | 赋予权利但不是义务买卖资产    | 风险可变    | 收益可变   | 中   | 经验丰富的投资者、策略交易者 |

## 评价指标词条介绍

### 评价投资收益 / 风险的指标

**总回报率（Total Return）**  是一项投资在特定时期内所有来源的最终价值增长百分比，其数值囊括了资本利得（或损失）与投资期间所产生的所有现金流收入（如股息、利息等）再投资的综合效应。简化公式为：`总回报率 = [(期末价值 + 期间现金流收入) / 期初价值] - 1`。

**年化收益率（Annualized Return）** 是将一段投资期内（无论长短）的实际收益，通过复利计算公式（即投资收益会作为本金进行再投资）折算为相当于投资满一整年后的可比较收益率。简化公式为：
`年化收益率 = [(1 + 投资期内总收益率) ^ (365 / 投资天数)] - 1`。

**超额收益（Excess Return）** 是一项投资的实际回报率超过某一特定基准回报率（如市场指数、无风险利率或自定义目标）的差额部分，简化公式为：`超额收益 = 投资组合的实际收益率 - 所选基准的收益率`。

**最大回撤率（Maximum Drawdown, MDD）**  是一种核心的、基于历史数据的风险衡量指标，其本质是在特定统计期间内，一项投资的净值从任一历史峰值点回落至最低谷点时，所产生的最大的百分比跌幅。最大回撤率提供对历史最糟糕持有体验的量化描述、揭示投资策略的潜在极端风险，并在风险管理与绩效评估中起到衡量下行风险控制能力、辅助投资者理解风险承受边界以及优化资产配置的关键作用。

**下行标准差（Downside Deviation）**是衡量投资组合或资产收益率低于某一特定目标（通常是零或无风险利率）的波动程度。它将“风险”的定义从宽泛的“不确定性”聚焦到更精确的“遭受损失的可能性”，因此只关注“坏的波动”，即亏损或收益未达预期的风险，而忽略“好的波动”（即上涨带来的波动）。其简化公式为：`下行偏差 = 收益率 - 目标收益率` （仅当收益率 < 目标收益率时计算，否则为0）

**波动率（Volatility）**  是运用统计学方法衡量投资收益率围绕其平均值（预期收益率）的离散程度与波动幅度。由于标准差能直观反映数据偏离均值的程度，因此波动率通常用年化标准差表示，标准差/波动率的数值越大，代表资产风险越高。

**夏普比率（Sharpe Ratio）**  是投资组合或资产在统计期内所获得的超额回报（即高于无风险利率的收益）与其总波动性（以收益率的标准差衡量）之间的比值。夏普比率提供跨资产、跨策略的统一绩效比较基准、表示承担的每一单位风险，能够换来多少超额回报。其简化公式为：`夏普比率 = (投资组合的预期收益率 - 无风险利率) / 投资组合收益率的标准差`。

**索提诺比率（Sortino Ratio）** 是投资组合的超额回报（高于最低可接受回报的部分）与其下行风险（以下行标准差衡量）之间的比值。索提诺比率提供对下行风险的针对性评估、揭示投资策略控制损失的有效性，表示承担的每一单位下行风险，能够换来多少超额回报。其简化公式为：`索提诺比率 = (投资组合预期收益率 - 最低可接受回报) / 下行标准差`。

| 指标类别               | 指标名称   | 核心解读                                                 | 适用场景                                                   |
| ---------------------- | ---------- | -------------------------------------------------------- | ---------------------------------------------------------- |
| **收益指标**           | 总回报率   | 整个投资期间的总盈利能力，不考虑时间跨度                 | 初步直观地了解投资的最终成果                               |
|                        | 年化收益率 | 将不同期限的投资回报转化为可比较的年度平均收益率         | 用于横向比较不同投资周期、不同产品收益表现的首要标准       |
|                        | 超额收益   | 投资组合收益超越其业绩比较基准的部分                     | 衡量主动管理能力。判断投资者是否真正创造了附加价值         |
| **风险指标**           | 波动率     | 投资收益率的总体波动程度。标准差越大，价格波动越剧烈     | 衡量投资组合的总体不确定性或波动风险。是计算夏普比率的基础 |
|                        | 下行标准差 | 投资收益低于某一目标（如0或无风险利率）的"坏"波动程度    | 更精准地衡量下行风险。适用于更关注亏损而非上涨波动的投资者 |
|                        | 最大回撤率 | 在选定时期内，从任一高点下跌到后续低点的最大峰值亏损幅度 | 衡量历史上最极端的亏损情况和投资者的心理承受极限           |
| **风险调整后收益指标** | 夏普比率   | 每承受一单位总风险（波动率），能获得多少超额回报         | 适用于广泛比较不同类型、不同风险等级的投资组合             |
|                        | 索提诺比率 | 每承受一单位下行风险（下行标准差），能获得多少超额回报   | 夏普比率的优化版。适用于更担心亏损的投资者                 |

### 评价投资价值的指标

**市盈率（Price-to-Earnings Ratio, P/E）** 是衡量股票价格相对于每股收益的比率，即为盈利支付的价格。通过股票市场价格除以每股收益（EPS）计算得出，更适用于评估盈利稳定、成长性明确的公司。

**市净率（Price-to-Book Ratio, P/B）** 是衡量股票价格相对于每股净资产的比率，即为净资产支付的价格。通过股票市场价格除以每股净资产计算得出，更适用于评估重资产、周期性行业、金融类公司，此外，大盘指数或宽基指数进行估值也可以使用此基准。

**股息率（Dividend Yield）** 是衡量股票年度现金分红相对于当前股价的比率，即投资者每投入一元所能获得的现金回报。通过每股年度股息除以当前股价计算得出，更适用于评估盈利稳定、持续分红的成熟企业，如银行、公用事业和房地产信托等高股息行业。

**风险溢价（Risk Premium）**是投资者因承担额外风险而要求的超额回报，其简化公式为：
`风险溢价 = 风险资产的预期收益率 - 无风险利率`

### 评价市场环境的指标

**无风险利率（Risk-Free Rate）** 是衡量一笔资金在绝对安全、不存在任何违约风险的前提下，于特定期限内所能获得的最低理论回报率在现实中，绝对的“无风险”资产并不存在，但在现实中通常以主权国家发行的短期国债（如美国3个月期国债）利率作为其代理变量。

**隐含波动率（Implied Volatility, IV）**又称“恐慌指数”， 是期权市场价格中蕴含的未来波动预期，是将场内期权的当前市场价格，代入期权定价模型（如布莱克-斯科尔斯模型）后，反解出的标的资产在未来期权存续期内的预期波动率数值。其本质是：若期权当前市场价格合理，对应的波动率应为多少？ 因此，IV反映了市场对未来一段时间内资产价格波动幅度的预期。市场预期事件冲击越大、不确定性越高、投资者越恐惧，则隐含波动率通常上行，反之亦然。

## 基金相关词条介绍

**ETF基金（交易所交易基金，Exchange-Traded Fund）**，又叫做场内基金，是一种在证券交易所上市交易的开放式基金，它通常跟踪特定指数（如股票指数、债券指数或商品价格），是一篮子股票、债券或其他资产的组合，同时兼具股票和基金的共同特点：既像股票一样可在交易时段实时买卖、价格波动，又像指数基金一样分散投资、费用较低。优势在于：ETF单位净值通常较低，因此拥有低投资门槛；通常跟踪特定行业指数或宽基指数，波动平稳；采用被动管理策略，综合成本低廉；

**ETF联接基金（ETF Link Fund）**是一种场外开放式基金，其核心特点是主要投资于对应的ETF（目标ETF）。由于ETF无法场外交易，因此通常将不低于90%的基金资产用于购买同一标的指数的ETF份额，从而间接实现对指数的跟踪。ETF联接的存在，扩展了ETF的规模和流动性。

**LOF基金（上市型开放式基金，Listed Open-Ended Fund）**是一种既可以在场外申购和赎回基金份额，又可以在场内像交易股票一样交易的基金，增加了交易弹性。由于同一只LOF基金存在场内价格和基金净值两个交易价格，因此只要两个交易价格之间的差额覆盖手续费后，就有会出现套利机会。LOF基金种类比ETF基金种类更多，但交易低迷，流动性更差：LOF的申购是T+1日确认，T+2日才可以卖出或赎回，且交易费用较ETF高。

-----------

**主动管理型基金**，是指由专业基金经理及其研究团队主导投资决策，通过主动选股、行业轮动、市场择时等策略，超越业绩比较基准以获取超额收益（Alpha）的基金类型。其运作机制基于市场非完全有效的假设，因此高度依赖基金经理的投研能力，其投资组合通常呈现高主动权重、高换手率的特点，并伴随较高的管理费率与相对较低的透明度。因此，主动基金的成功与否，与基金经理个人能力的持续性与稳定性密切相关。

**被动管理型基金**，是指以复制特定指数表现为唯一目标，通过完全复制或抽样复制指数成分股及其权重，力求跟踪误差最小化的基金类型。其运作建立在有效市场假说的理论基础之上，因此严格遵循指数编制规则，从而获取市场的系统性回报（Beta）。被动基金的核心优势在于透明度高）、成本低廉（总费率通常低于0.6%）、分散风险，且长期表现稳定。其局限性在于无法规避系统性风险，且无法获取超额收益。

**指数增强型被动基金**，是指在以跟踪某一特定市场指数（如沪深300、中证500）为基准的前提下，通过采用量化和基本面的主动管理策略，旨在持续、稳定地超越基准指数获得超额收益的基金。其目标收益是Beta + Alpha：它不满足于只获得市场平均回报（Beta），而是寻求在Beta的基础上，增加一部分稳定的超额收益（Alpha），由于有跟踪误差的约束，其投资组合不会像纯主动基金那样大幅偏离市场，下行风险相对可控。

-----------

**A、B、C类基金**，是指在基金投资中，A、B、C类份额实质上代表的是同一只基金产品下，为满足不同投资者持有期限和成本偏好而设立的不同收费份额类别。

+ A类份额采用前端收费模式。投资者在申购时即需支付一笔一次性的申购费。在基金的持有期间，A类份额不收取销售服务费。此设计非常适合有长期投资计划的投资者。因为初始的申购费是一次性成本，随着持有时间的延长，这笔费用会被摊薄，年化持有成本会显著降低。

+ C类份额则采用后端收费的一种形式，具体为按日计提销售服务费。投资者在申购时无需支付申购费，但在整个持有期间，基金会每日从资产净值中计提一笔销售服务费。此模式专为中短期或波段操作的投资者设计。由于其没有初始费用，进出灵活，短期交易成本低。然而，如果持有时间过长（例如超过一年或两年），累计支付的销售服务费可能会超过A类份额的申购费，变得不经济。
+ B类份额是另一种后端收费模式，其费用在赎回时发生。投资者申购时免费，赎回时根据持有期限的长短来支付赎回费，持有时间越长，费率越低，通常持有足够长的时间后可免除。由于此模式设计相对复杂，且不如A/C类份额能清晰地区分长短期投资者，因此在目前的公募基金市场中已非常少见，基本被A类和C类份额所取代。

---------------

**ETF运作原理**：

ETF（交易所交易基金）是一种同时在一级市场和二级市场运作的创新型基金产品，其独特机制使其既能紧密跟踪指数，又能像股票一样实时交易。

在一级市场，只有获得授权的机构，包括ETF发起人（如华夏基金等基金管理人）、参与交易商等才能进行ETF份额的大额增设（申购）与赎回。参与交易商通常需提交至少50,000份或更多的创设单位（按市价可能值几十万甚至上百万元），参与交易商需向ETF发起人交付一份与所跟踪指数成分完全一致的“证券篮子”（称为实物申购），也可全部或部分使用现金；该证券篮子的内容和权重每日由ETF发起人公布，严格反映指数构成，确保ETF资产与目标指数高度一致。 

ETF在设立时，并不会让每份价格等于指数点位，而是将整个指数资产“按比例缩放”，设定一个较低的初始净值（如1元或3元），使得1份ETF代表指数的一小部分。这样做的目的是降低投资门槛——普通投资者只需几百元就能买一手（100份），提升交易便利性和市场流动性。

这些由一级市场生成的ETF份额随后进入二级市场，即证券交易所，供普通投资者通过券商像买卖股票一样交易。由于这类交易不涉及ETF基金本身的资产变动——你买的是其他投资者或做市商手中的份额，而非从基金公司直接申购，因此不会触发基金买卖股票、支付佣金等操作，大幅降低了整体运营成本，这也是ETF费率通常显著低于传统共同基金的重要原因

此外，由于其二级市场价格由本地供需决定，而非依赖境外指数的实时变动，因此跨境ETF（如恒生ETF、纳指ETF）能在境外市场休市时于A股正常交易。这种双市场结构使ETF兼具指数跟踪、交易灵活、成本低廉三大优势。

### 技术类指标词条介绍

**K线**：是一种用于表示特定时间周期（如日、周）内证券价格变动的图表。其结构包含开盘价、收盘价、最高价和最低价。实体部分表示开盘与收盘价之间的范围，若收盘高于开盘则为阳线（常为红色），反之为阴线（常为绿色）。上下影线则分别指示该周期内的最高价和最低价，直观地展示了多空双方的力量对比。

**五档价格**：是指在竞价交易系统中，于当前时刻挂出的最接近当前市价的五个买入价（买一至买五）和五个卖出价（卖一至卖五），以及其对应的委托数量。它揭示了市场即时的潜在买卖意愿和流动性，为交易者提供最直接的买卖压力参考，帮助判断挂单支撑与阻力的强度，并作为下单决策（如限价委托）的重要依据。

**均线（MA）**：是一种将特定周期内的证券平均价格连接而成的趋势线。常用周期有5日（MA5）、10日（MA10）等。其主要作用是平滑价格数据，以消除短期波动，从而更清晰地显示价格趋势方向和强度，通过不同周期均线的交叉（如金叉、死叉）可以提供趋势动能的买卖信号。一般而言，30日以内为短期均线，60日以内为长期均线，120日以后为长期均线。

**成交量**：是指在某一时间段内（通常为一个交易日）某证券成交的总股数或手数。它是衡量市场交易活跃程度和资金参与热情的核心指标。其作用是确认价格变动背后的资金推动力度和可靠性。健康的趋势通常需要成交量的配合（价升量增），而量价背离（如价升量缩）则往往预示着当前趋势可能难以持续。

**BBI**：多空指标的简称，它是一种通过将不同周期的移动平均线（如3日、6日、12日、24日）再进行平均计算后得到的复合型均线指标。其目的是综合不同时间维度的市场平均成本，用以判断市场的多空趋势。当价格运行于BBI之上视为多头市场，之下则为空头市场，为操作提供简明趋势依据。

**ENE**：ENE是轨道线的简称，它由一条中轨（通常为N日移动平均线）和两条围绕中轨上下对称分布的轨道线（上轨和下轨）构成。轨道线的宽度由设定的幅度参数决定。该指标的主要功能是标识价格运行的潜在通道，当价格触及轨道线时可能产生回调或反弹，为波段操作提供参考的边界和时机。

**EXPMA**：是指数平滑移动平均线的简称。与简单移动平均线对所有时期数据赋予相同权重不同，EXPMA采用了指数加权的计算方法，在保留均线趋势跟踪功能的同时，通过赋予近期价格更高权重，来更快地反映价格的最新变化。这减少了指标信号的滞后性，能更灵敏地捕捉趋势的启动与转折点。

**筹码分布**：筹码分布是一种通过模拟算法，将不同价位的成交量分布情况在图表上立体展现出来的技术分析方法。其核心是展示在所有流通股本中，当前持股者的成本集中在哪些价格区域。通过识别筹码密集区（支撑或阻力）和筹码的移动情况，可以判断主力资金的动向、市场整体的获利或套牢压力。

**换手率**：换手率也称“周转率”，是指在特定时期内，证券转手买卖的频率。其计算公式为：成交量 / 流通总股数 × 100%。它是衡量股票流动性强弱和市场交投活跃度的关键指标。较高的换手率通常意味着交易活跃，流动性好；而过高的换手率也可能预示投机性强或筹码不稳定。

**量比**：量比是衡量相对成交量的指标。它是开市后每分钟的平均成交量，与过去5个交易日每分钟平均成交量之比。其计算公式为：（当日即时成交量/开盘至今的累计分钟数） / （过去5日总成交量 /  1200分钟）。量比数值大于1表示当日此时的成交活跃度高于过去5日的平均水平，小于1则表示活跃度低于平均水平。它常用于盘口分析，以判断当日成交量的异动情况。

**MACD（指数平滑异同移动平均线）**，是一种用于研判价格趋势、动量、强度及转折点的经典技术分析工具。该指标主要由三个部分组成一个协同系统（两条曲线和一个红绿柱）：

+ **DIF（差离值）**，是由快速（通常为12日）指数移动平均线减去慢速（通常为26日）指数移动平均线得出。它代表股价短期与长期趋势的“离差值”，能够灵敏地反映当前价格动能的方向与强度。当DIF由下而上穿越零轴，预示多头趋势可能开启；反之，则可能进入空头市场。

+ **DEA（信号线）**：是DIF的移动平均（通常为9日），作为DIF的“平滑版”，它起到过滤噪音、确认趋势稳定性的作用。DEA的走势比DIF更为平缓，其与DIF的相对位置关系是生成交易信号的关键。当DIF从下方上穿DEA形成“黄金交叉”，视为买入信号；下穿形成“死亡交叉”则为卖出信号。

+ **MACD柱状图**，直观展示了DIF与DEA之间的差值（DIF-DEA），以零轴为中心的柱线长短变化描绘了多头与空头动能的加速或衰减。柱状线的伸长表明趋势动能增强，收缩则预示动能减弱。当柱状线在零轴上方由缩转伸，代表上涨动能复苏；在零轴下方由缩转伸，则代表下跌动能加剧。其“斜率”变化往往领先于DIF与DEA的交叉信号。

**BOLL（布林线）**是一条移动平均线（通常为20日简单移动平均线）作为中轨和在其上下两侧的通道线构成。上方通道线（上轨）是移动平均线加上两倍标准差，代表价格动态的阻力边界；下方通道线（下轨）是移动平均线减去两倍标准差，代表价格动态的支撑边界。通道的宽度会随市场波动率的变化而自动调整：波动加剧时通道变宽，波动减小时通道收窄。

+ **BOLL指标喇叭口形态**：BOLL上轨上涨，下轨下跌，中轨存在向上趋势，此时股价往往伴随上升趋势呈现上涨姿态。
+ **BOLL指标的下轨支撑**：当股价跌至BOLL指标下方时，表示多空双方势均力敌，有可能形成支撑点位；

### 常见股市经验词条介绍

**支撑位**，是指价格下跌时可能遇到买方支撑，从而止跌或反弹的关键价格水平。该位置通常由前期密集成交区的低点、重要移动平均线或市场心理关口构成（如30日均线等）。当价格接近支撑位时，买方需求预计会增强，卖方力量减弱，从而形成一道“价格地板”。若支撑位被有效跌破（通常伴随成交量放大），则意味着下跌趋势可能延续，该支撑位随后将转变为新的阻力位。

**阻力位**，是指价格上涨时可能遇到卖方抛压，从而止涨或回落的关键价格水平。该位置通常由前期密集成交区的高点、前期显著下跌的起点或重要的趋势线构成。当价格接近阻力位时，卖方供给会集中出现，买方力量受限，从而形成一道“价格天花板”。若阻力位被有效突破（通常需放量确认），则标志着上涨空间被打开，该阻力位在未来回调时通常会转变为新的支撑位。

**黄金交叉（金叉）**：是指10日均线（或其他短期均线）上穿30日均线（或其他长期均线）所形成的交叉，且短期均线、长期均线都为上升走势，表明短期交易价格已经超过长期交易价格，整体走势处于上涨行情中，买入机会出现。若MACD指标也形成金叉，则构成了双重金叉，趋势得到进一步加强。

**死亡交叉（死叉）**，是指10日均线（短期均线）下击30日均线（长期均线）所形成的交叉，此时短期均线呈现下降走势，长期均线走平或者下降，表示股价短期收到空方力量打压，开始出现下跌趋势。

**顶背离**，是出现在价格波段高点后的看跌信号。当价格创出新高而对应的MACD指标（通常指DIF线或柱状图高度）未能同步创出新高时形成。这表明尽管价格仍在上涨，但其内在的上涨动能正在减弱，上升趋势可能难以为继，预示市场即将见顶回落。它是多头力量衰竭的预警，通常被视为潜在的卖出信号。

**底背离**，是出现在价格波段低点后的看涨信号。当价格创出新低而对应的MACD指标未能同步创出新低时形成。这意味着尽管价格仍在下跌，但其内在的下跌动能正在衰竭，下降趋势可能即将结束，预示市场即将触底反弹。它是空头力量减弱的早期信号，通常被视为潜在的买入信号。

### 市场资金词条介绍

**两融资金**，即杠杆资金，是融资交易和融券交易的合称，用于增强市场流动性和提供杠杆交易的机会。它允许投资者通过杠杆借入资金或证券进行交易，实现融资买入和融券卖出两个方向操作。融资业务指投资者以自有资金作为保证金（通常不低于50%），向券商借入资金买入标的证券，投资者可以在资金有限的情况下增加投资金额，以期在市场上涨时获得更高的收益；融券业务则指借入证券卖出，待股价下跌后买回归还以赚取差价，这种方式允许投资者在市场下跌时获利，增加了投资策略的灵活性。

**北向资金**，作为跨境资本配置中国权益资产的核心渠道，系指通过沪港通、深港通机制由境外投资者（以主权财富基金、对冲基金、养老基金及国际资管机构为主导）流向A股市场的资金。它反映出跨境资本对海外流动性环境的敏感性，其交易行为也会对A股微观结构产生系统性影响；

**南向资金**，作为境内资本跨境配置港股资产的关键通道，系指通过沪港通、深港通机制由内地投资者（以公募基金、保险资金、私募机构及高净值个人投资者为主体）流向香港资本市场的资金。它反映出内地资本对港股市场估值优势与政策导向的敏锐性，其持续流入不仅强化了香港市场的流动性基础，亦对港股定价机制与行业结构产生深远影响，同时体现了中国资本账户双向开放进程中的资产全球化配置趋势。

**主力资金**，作为衡量场内核心驱动力与资金趋向的关键指标，系指在特定证券市场中对个股或板块价格走势具有显著影响力、且交易行为具备系统性特征的大型机构投资者及超级个人投资者所掌控的资金集群（公募基金、券商自营盘、保险资金、社保基金、私募基金）。其运作模式区别于散户投资者的零散化、情绪化交易，通常呈现体量庞大、策略前瞻、协同性强的特征。交易所每日公布的龙虎榜数据、大单净流入/流出、以及各类资金流向统计工具，是追踪主力资金动向、解码其战略意图的重要窗口。

**游资**，是指在股票市场中寻求短期高额回报的投机性资金，其操作主体通常为体量庞大的个人投资者或私募机构。核心操作理念是追逐市场热点、题材概念，利用资金优势制造赚钱效应，通过快速建仓、强势拉升并迅速派发的方式，在短期内完成“点火、拉升、出货”的全过程。

### 资金操作词条介绍

**集合竞价**：是指在每个交易日开盘前（及收盘前部分市场）的特定时段内，交易所对所有有效买卖申报一次性集中撮合，以产生统一成交价格（开盘价或收盘价）的交易机制。

+ **开盘集合竞价**：每个交易日的 9:15 至 9:25。其中，9:15–9:20：投资者可提交或撤销买卖申报；9:20–9:25：可提交申报，但不可撤销；9:25：系统对所有有效委托按最大成交量原则一次性撮合，产生当日开盘价，并公布开盘结果。
+ **收盘集合竞价**：每个交易日的 14:57 至 15:00。其中，14:57–15:00：可提交买卖申报，不可撤单；15:00：系统集中撮合，产生当日收盘价。

**股指期货交割日**，是指期货合约到期的最后交易日（国内通常为合约到期月份的第三个星期五），买卖双方根据合约规定进行资金清算，以了结未平仓头寸。股指期货交割日对股市的影响主要体现在短期内可能加剧市场波动，这一过程被称为“交割日效应”。其核心机制在于，在交割日当天，未平仓的期货合约必须按照标的指数的特定结算价进行现金交割。为了确保交割利润最大化或避免损失，交易者（尤其是持有大量头寸的机构）会在现货市场（即股票市场）进行相应的操作，从而影响股价。

**洗盘**，是主力资金为达成战略拉升目的而采取的强制性控盘手段，其本质是通过制造价格波动与市场恐慌来诱导错误判断。具体而言，洗盘旨在清理浮动筹码、垫高市场平均持仓成本，并在震荡中实现低位增仓。与真正出货的根本区别在于，洗盘是主力为后续上涨而进行的“假破位”与持仓结构优化，是趋势启动前的关键蓄力阶段。

**派息**，是上市公司将其税后利润的一部分，以现金形式分配给股东的投资回报，是股东作为公司所有者分享经营成果的直接体现。公司董事会根据盈利状况宣布派息方案（宣布日），随后在股权登记日收盘时持有股票的股东有权获得此次分红。到了除息日，股票市场价格会扣除每股股息的金额，股东账户在获得现金股息的同时，其股票市值会相应下调（除权除息，总资产理论上保持不变）。最终在派发日，现金股息会正式存入股东的账户。对于追求稳定现金流的投资者，高股息股票常作为防御性配置。与之相对应，成长型公司（如科技、生物医药）往往选择留存利润用于研发扩张，较少分红，其价值更多体现在资本利得而非股息收益。

**打新**，即参与新股首次公开发行（IPO）申购，是投资者通过证券账户认购新发行股票并期待上市后获利的行为。历史数据显示，主板新股上市首日涨幅通常为44%，而科创板、创业板因无涨跌幅限制，首日波动更大，因此可以通过申购新上市股票进行获利。

**股票打板**，是A股短线交易策略中高风险高收益的操作方式，指投资者在股票触及涨停价且存在成交机会时买入，博取次日继续上涨收益的行为。由于股票触及涨停价时会引发市场关注，积累次日买盘，创造高开预期，因此第二日上涨概率较大，本质上是利用了A股的T+1制度和人性中的贪婪与恐惧。

**债券逆回购**，是金融市场中的一种短期融资行为，资金融出方通过债券市场买入债券，以国债等优质债券作为抵押品，由交易所实行中央担保交收，并约定在未来特定日期以稍高价格卖回给融入方，其中的价差即为利息收益。其主要特点包括期限高度灵活（1天至182天不等）、信用风险极低，流动性强且操作便捷。它一方面为持有多余资金的投资者提供安全可靠的短期理财工具，另一方面帮助金融机构快速补充流动性。

## 宏观经济术语介绍

-------------

### **货币供应量**统计指标

**M0（流通中现金）**：M0是货币供应统计中最窄的口径，指金融体系以外的企业、团体及个人所持有的实物现金。它构成了货币体系中最直接、流动性最强的支付工具，是经济活动中即时的购买力体现，也被称为基础货币的一部分。

**M1（狭义货币供应量）**：M1在M0的基础上，加上了企业的单位活期存款。这部分资金可以随时通过开支票、转账等方式直接进行支付，无需任何转换。因此，M1主要衡量的是现实购买力，其增速变化被视为衡量企业投资意愿和经济短期景气度的灵敏指标。

**M2（广义货币供应量）**：M2在M1的基础上，进一步纳入了企业定期存款、居民储蓄存款及其他存款。这些资金虽然不能直接用于支付，但通过一定程序（如提前支取、赎回）可以较为容易地转化为现实的购买力，代表了潜在购买力与总购买力。M2是衡量社会总需求和未来通胀压力的关键宏观指标，也是货币政策调控的核心中介目标。

**货币剪刀差**：即M1-M2增速差，是一个关键的先行观测指标，它通过追踪货币在“现实购买力”（M1）与“潜在购买力”（M2）之间的流动，来预判经济的短期走向与活力。当M1增速快于M2增速时，表明交易活动活跃，投资与消费意愿增强，预示着实体经济活力提升，是经济趋于活跃的积极信号；当M2增速快于M1增速时，实业投资机会匮乏，消费与投资意愿低迷，这是经济活力下降、可能步入下行周期的警示信号。

### 宏观经济指标

**GDP（国内生产总值）**：是衡量一个国家或地区所有常住单位在一定时期内生产活动最终成果的总量指标，是评估经济总体规模与增长的核心尺度。通常以同比或环比增速来反映经济的扩张与收缩，代表经济发展的长期趋势。其理论计算有三种方法，但各国统计实践各有侧重，中国则在季度核算中主要依赖生产法，并在年度核算中努力平衡三种方法。：

- **生产法**：从生产过程中创造价值的角度，计算各产业部门增加值的总和（GDP = 总产出 - 中间投入）。中国在进行季度GDP初步核算时主要采用的方法，因为它能快速、直接地反映生产端的经济活动。
- **收入法**：从生产过程形成收入的角度，计算所有常住单位在一定时期内创造的收入总和（GDP = 劳动者报酬 + 生产税净额 + 固定资产折旧 + 营业盈余）。美国等国家将其作为验证和调整支出法结果的重要依据。
- **支出法**：从最终使用的角度，计算所有常住单位在一定时期内最终产品和服务的支出总和（GDP = 消费 + 投资 + 净出口，即三驾马车）。绝大多数国家如美国、德国、日本等，将支出法作为其年度GDP核算和国际比较的核心方法。

**PMI（采购经理指数）**：是国家统计局对采购经理人进行问卷调查得到的一系列指数，代表经济发展的中短期趋势，是观测宏观经济走势的最及时的指标之一。其计算通过对新订单、生产、雇员、供应商配送时间、主要原材料库存五个子指数进行加权综合，并进行季节性调整。该指数以50%作为荣枯分水线：高于50%反映经济总体扩张，低于50%则反映收缩。其优势在于时效性强，能灵敏地预示经济活动的短期变化方向。

**CPI（居民消费价格指数）**：是反映居民家庭购买的消费品和服务项目价格水平变动情况的指标，用于衡量通货膨胀（或通货紧缩） 的程度。其计算基于一篮子预先确定的商品与服务（如食品、衣着、居住等），雇佣价格采集员进行抽样检测，通过跟踪其价格变化并依据各自在居民消费中的重要性进行加权平均得出。它衡量的是最终消费环节的价格变动，直接关系到居民生活成本和货币购买力。CPI快速增长（同比3%）时，央行会减少放水防止通过膨胀，不利于债市和股市；当CPI增长过慢或者负增长时，表明经济活力不足，央行会适当的放水阻止通缩；

**PPI（工业生产者出厂价格指数）**：是衡量工业企业产品出厂价格总水平变动趋势和程度的指数，代表生产端管理者的整体生产成本。其计算方法是调查数以千计的代表性工业产品的出厂价格，并依据其行业权重进行加权平均。它反映了生产领域的价格变动，并会通过产业链（生产资料→生活资料）向CPI传导。PPI的波动常被视为CPI的先行信号，同时也是整体经济的滞后指标。
